# 販売を生むための運用手順（Okonomi Press）

自動化されている部分（毎日の投稿、メンションへの返信、反応の計測、撤退判定）以外で、人が動く部分と、販売開始のときにやることをまとめる。運営エージェントは、日報で該当する手順をオーナーに促す。

## 1. 毎日10分の手動の交流（オーナー）

ボットにはできない、最初の観客を作るための作業。

- **3分：自分への反応に全部返す**。返信・引用・メンションには必ず一言返す（アドレス付きのメンションは自動返信されるので、それ以外）。
- **5分：他人の投稿に3件、中身のある返信をする**。Xで「onchain art」「generative art」「Base NFT」「NFTアート」の最新の投稿を見て、フォロワー1千〜2万人くらいのアカウントを選ぶ（大きすぎるアカウントは埋もれる）。作品の感想や質問を書く。リンクや宣伝は書かない。
- **2分：持ち主のシェアを拾う**。誰かが作品をシェアしていたら、引用して紹介する。

## 2. 日本のコミュニティ（オーナー＋エージェント）

- 投稿に日本語を一言添えている（エージェントが担当）。日本語中心の投稿を1日1本に増やすかは、反応を見てエージェントが提案する。
- ハッシュタグは1投稿に2つまで：`#NFTアート` `#ジェネラティブアート` `#onchainart` `#Base` から選ぶ。
- 週1回、日本語のNFT関連のXスペース（音声配信）を聴き、可能なら発言する。「NFT スペース」で検索すると見つかる。
- 週に5人まで、ジェネラティブアートやオンチェーン作品を集めている日本のコレクターに、作品の紹介をDMする。定型文の一斉送信はしない。

## 3. 販売開始の手順（エージェントが承認依頼を出し、オーナーが承認）

1. **1本ずつ出す**。反応が一番良い案だけを販売開始する。
2. **最初の30枚は無料（ガス代のみ）**にする。持ち主の数を先に作るため。コントラクトに「最初のN枚は無料」の設定を追加してから出す（未実装。最初の販売開始のときに実装する）。
3. **前日に予告**を投稿する：「明日、日本時間23時（米国の朝）に販売開始。最初の30枚は無料」。
4. **当日**：販売開始の投稿を固定表示にする。節目（1、10、25、50枚…）の投稿はボットが自動で出す。
5. **翌日**：振り返りの投稿（何枚売れたか、印象的な作品）を1本出す。

## 4. Farcaster（保留）

2026年に運営元が2回変わり（1月に Neynar、10月に Network School）、名称変更・新しい利用規約・本人確認の導入が進んでいる。Base アプリも2026年2月に Farcaster のフィードを外した。状況が落ち着くまでは優先しない。Xでの販売が軌道に乗り、Farcaster 側の方針が固まったら、改めて検討する。

## 5. アクセス解析（オーナーが1回だけ設定）

Cloudflare の無料アカウントで Web Analytics を有効にし、表示されるトークンを `config.json` の `analytics.cloudflareToken` に入れる。ミントページの閲覧数がわかるようになる。

## やらないこと

フォロワーの購入、自動いいね・自動リポスト・自動フォロー、同じ内容の複数アカウント運用、トレンドへの自動便乗、自作自演の購入。どれもアカウント凍結や信頼の喪失につながる。
